# Qwen2.5 Mobile Chat

A premium, modern chat application using Qwen2.5 0.5B (GGUF) running locally via LangGraph.

## Features
- **Fast Inference**: Q6_K Quantization.
- **Tools**: Real-time Clock & Tavily Search.
- **UI**: Premium minimalist design with Chat History.
